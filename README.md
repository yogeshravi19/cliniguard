# CLINIGUARD Project

**Objective**: A safety guardrail for LLM‑generated medical answers that detects hallucinations and unsafe content.

## Repository Structure
```
cliniguard/
├─ data_extraction/      # Code to download & preprocess each dataset
├─ analysis/            # Feature extraction, fusion, and evaluation scripts
├─ reports/             # Figures, tables, and final presentation files
├─ scripts/             # Core pipeline scripts (load_datasets.py, cliniguard_pipeline.py)
├─ notebooks/           # exploratory Jupyter notebooks
├─ config/              # configuration files and requirements
└─ README.md            # this file
```

Refer to the sub‑folder READMEs for detailed instructions.

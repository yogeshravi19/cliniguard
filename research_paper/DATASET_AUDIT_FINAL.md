## 2. In-Depth Analysis of Individual Datasets

### 2.1 Med-HALT (openlifescienceai/Med-HALT) — INCLUDED (Genuine)
* **Citation**: Pal, Umapathi, Sankarasubbu. "Med-HALT: Medical Domain Hallucination Test for Large Language Models." *CoNLL 2023*. arXiv:2307.15343.
* **HuggingFace Config**: `IR_abstract2pubmedlink`
* **Original Dataset Composition**: 4,916 total rows (4,914 valid after non-empty answer filtering).
* **Ground Truth Mechanics**:
  - `label = 0` (`real_data`): 2,925 authentic biomedical paper abstracts sourced directly from PubMed.
  - `label = 1` (`fake_data`): 1,989 hallucinated biomedical abstracts generated by LLMs with fabricated scientific claims, imaginary methodologies, and fictitious findings.
* **Text Characteristics**:
  - Label 0 Mean Answer Tokens: 208.0 tokens.
  - Label 1 Mean Answer Tokens: 127.3 tokens.
  - Unique Questions / Titles: 4,817.
* **Suitability**: High. Represents a peer-reviewed, standard hallucination evaluation benchmark for medical LLMs.
* **Loader Function**: `load_datasets.py -> extract_medhalt()`.

### 2.2 MedHallu (UTAustin-AIHealth/MedHallu) — INCLUDED (Genuine)
* **Citation**: Pandit et al. "MedHallu: A Comprehensive Benchmark for Detecting Medical Hallucinations in Large Language Models." *2025*. arXiv:2502.14302.
* **HuggingFace Config**: `pqa_labeled`
* **Original Dataset Composition**: 1,000 paired clinical items, yielding 2,000 total samples.
* **Ground Truth Mechanics**:
  - `label = 0` (`Ground Truth`): 1,000 authentic clinical answers curated by medical domain experts.
  - `label = 1` (`Hallucinated Answer`): 1,000 paired clinical answers generated by LLMs exhibiting fine-grained medical hallucinations (entity substitution, relation distortion, incorrect contraindications, and negation flip).
* **Text Characteristics**:
  - Label 0 Mean Answer Tokens: 39.7 tokens.
  - Label 1 Mean Answer Tokens: 27.8 tokens.
  - Unique Questions: 1,000. Each question appears exactly once with `label=0` and once with `label=1`.
* **Group Leakage Control**: In all cross-validation experiments, grouping is strictly enforced by `source + '|' + question` via `StratifiedGroupKFold`, ensuring that both variants of a question never span across train and test folds simultaneously.
* **Suitability**: High. Expert-annotated, realistic medical dialogue hallucination test set.
* **Loader Function**: `load_datasets.py -> extract_medhallu()`.

## 3. Audited and Excluded Datasets (Why Synthetic Labels Were Rejected)

### 3.1 MedHall-Bench (healthmemoryarena/MedHall-Bench) — EXCLUDED
* **Inspection**: Inspected the raw HuggingFace repository (`healthmemoryarena/MedHall-Bench` and `mirobody/MedHall-Bench`).
* **Original Structure**:
  - Files: `data/202604/factual-20260420.jsonl`, `data/202604/contextual-20260420.jsonl`, `results_sample.jsonl`.
  - Keys: `id`, `title`, `description`, `user`, `eval`, `tags`.
  - `user`: contains patient prompts (e.g. `strict_inputs: ["我今年52岁..."]`).
  - `eval`: contains evaluation rubrics, clinical background context, and `known_facts`.
  - `results_sample.jsonl`: an empty submission template `{"id": "...", "answer": ""}`.
* **What Went Wrong in Legacy Loader**:
  MedHall-Bench is a test harness designed for benchmarking external agent systems (via HolyEval). It does **not** provide pre-packaged LLM hallucination outputs.
  To simulate data, the legacy script:
  ```python
  # Legacy code in load_datasets.py lines 238-249:
  rows.append({"question": question, "answer": facts, "label": 0})
  rows.append({
      "question": question,
      "answer": (
          "我们建议一些不确定的治疗方案。这可能没用，或者导致严重的并发症如昏迷或死亡。"
      ),
      "label": 1,
  })
```
  This injected an identical hardcoded sentence into 100% of the positive rows. It is an artificial construction and completely uninformative of genuine hallucination detection.
* **Decision**: Excluded from primary hallucination evaluation.

### 3.2 PubMedQA (qiaojin/PubMedQA) — EXCLUDED
* **Inspection**: Peer-reviewed QA dataset from EMNLP-IJCNLP 2019 (Jin et al.).
* **Original Structure**: Authentic biomedical questions paired with PubMed abstracts and labeled with categorical answers (`yes`/`no`/`maybe`).
* **What Went Wrong in Legacy Loader**:
  PubMedQA does not contain hallucinations. The legacy loader artificially altered every 3rd row:
  ```python
  # Legacy code in load_datasets.py lines 127-132:
  if i % 3 == 0:
    answer = (
        "We suggest that it could perhaps be possible to assume some treatment"
        " options, maybe."
    )
    label = 1
```
  Because the injected sentence is constructed entirely of hedging words ("suggest", "perhaps", "possible", "assume", "maybe") that match CliniGuard's internal `UNCERTAIN_WORDS` lexicon, this created circular evaluation, inflating AUROC to a trivial 1.000.
* **Decision**: Excluded from primary hallucination evaluation.

### 3.3 MedQuAD (lavita/MedQuAD) & MedQuAD XML — EXCLUDED
* **Inspection**: Authentic consumer health question answering collection compiled from 12 NIH institutes by Ben Abacha & Demner-Fushman (*BMC Bioinformatics* 2019).
* **What Went Wrong in Legacy Loader**:
  MedQuAD contains authentic, verified medical guidance. It contains zero annotated hallucinations.
  - In `lavita/MedQuAD`, the legacy loader assigned:
    ```python
    df["label"] = (df.index % 3 == 0).astype(int)
```
    leaving the authentic answer text completely unchanged. This meant label 1 was indistinguishable from label 0 in terms of text content, yielding random ~0.50 AUROC on held-out test data.
  - In `MedQuAD XML`, the same synthetic hedging sentence was injected.
* **Decision**: Excluded from primary hallucination evaluation.

## 4. Final Dataset Partitioning for Paper Evaluation

The final research paper relies **strictly and exclusively** on the 6,914 genuine benchmark instances:

| Dataset | Training Partition (70%) | Testing Partition (30%) | Total Verified Instances |
|---|---:|---:|---:|
| **Med-HALT** | 3,461 | 1,453 | 4,914 |
| **MedHallu** | 1,378 | 622 | 2,000 |
| **Pooled Genuine Benchmark** | **4,839** | **2,075** | **6,914** |

No fabricated answers, synthetic hedging injections, or pseudo-labels are used anywhere in the experimental results of the final manuscript.

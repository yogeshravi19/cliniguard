#### Slide 9 – CLINIGUARD Feature‑Extraction Engine (4 Signals)

**1. Med‑ISP (Drug & Dosage Probe)**
```
risk = 1.0 – min(drug_hits / (word_count * 0.05), 1.0)
```
**2. C‑AAS (Context Attention)**
```
risk = 1.0 – min(context_hits / (word_count * 0.04), 1.0)
```
**3. Med‑EEM (Entropy / Uncertainty Monitor)**
```
risk = min(hedge_hits / (word_count * 0.02), 1.0)
```
**4. CDT (Clinical Drift Tracker)**
```
overlap = |Q ∩ A| / |Q|
risk = 1.0 – min(overlap * 2, 1.0)
```
